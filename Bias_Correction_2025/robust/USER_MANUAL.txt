================================================================================
                              1. OVERVIEW
================================================================================

This system implements MSUA-Net (Multi-Scale U-Net with Attention) for 
precipitation bias correction. It corrects systematic errors in NWP (Numerical
Weather Prediction) model output using deep learning.

KEY FEATURES:
- Multi-scale feature extraction (3x3, 5x5, 7x7, 9x9 convolutions)
- Attention mechanisms (SE, CBAM, Attention Gates, Self-Attention)
- Graph Neural Network for spatial relationships (NOVEL!)
- Uncertainty quantification (predicts confidence intervals)
- ~149 million parameters (state-of-the-art capacity)
- Production-grade training infrastructure

================================================================================
                          7. TROUBLESHOOTING
================================================================================

PROBLEM: "No module named 'robust'"
-----------------------------------
SOLUTION: Make sure you're in the correct directory:
    cd "e:\iitm pune project important files\MY FILES\Bias_Correction_2025"


PROBLEM: "CUDA out of memory"
------------------------------
SOLUTION: Reduce batch size:
    python robust/scripts/train.py --config robust/config/production.yaml --batch_size 8

Or run on CPU (slower):
    python robust/scripts/train.py --config robust/config/production.yaml --device cpu


PROBLEM: "Unable to allocate memory for array"
-----------------------------------------------
SOLUTION: Your RAM is insufficient. Try:
    1. Close other applications
    2. Use smaller batch size
    3. Use lazy loading (enabled by default)


PROBLEM: "torch_geometric not found"
--------------------------------------
SOLUTION: Install PyTorch Geometric:
    pip install torch_geometric


PROBLEM: "Variable 'rf' not found in NetCDF"
---------------------------------------------
SOLUTION: Check variable name in your data:
    python -c "import xarray as xr; print(xr.open_dataset('your_file.nc').data_vars)"
    
Then update config: variable_name: "YOUR_VARIABLE_NAME"


PROBLEM: Training loss not decreasing
---------------------------------------
SOLUTIONS:
    1. Check data normalization - make sure data looks reasonable
    2. Try smaller learning rate: --lr 0.00001
    3. Check for NaN values in data
    4. Ensure input/output dimensions match

                       8. ARCHITECTURE DETAILS
================================================================================

MSUA-Net ARCHITECTURE:
======================

Input [B, 10, H, W]
        ↓
┌─────────────────────────────────────────┐
│  MULTI-SCALE FEATURE EXTRACTOR          │
│  (3×3, 5×5, 7×7, 9×9 parallel branches) │
└─────────────────────────────────────────┘
        ↓
┌─────────────────────────────────────────┐
│  U-NET ENCODER (4 levels)               │
│  - DoubleConv + ResidualBlocks          │
│  - SqueezeExcitation attention          │
│  - MaxPool between levels               │
└─────────────────────────────────────────┘
        ↓
┌─────────────────────────────────────────┐
│  BOTTLENECK                             │
│  - Self-Attention (Transformer-style)   │
│  - Graph Neural Network (NOVEL!)        │
│  - ResidualGroup                        │
└─────────────────────────────────────────┘
        ↓
┌─────────────────────────────────────────┐
│  U-NET DECODER (4 levels)               │
│  - Upsample + Attention Gates on skips  │
│  - DoubleConv + ResidualBlocks          │
└─────────────────────────────────────────┘
        ↓
┌─────────────────────────────────────────┐
│  UNCERTAINTY HEAD (Dual output)         │
│  - Mean prediction (NO activation!)     │
│  - Variance prediction (positive)       │
└─────────────────────────────────────────┘
        ↓
Output: Mean [B, 1, H, W], Variance [B, 1, H, W]

                    9. NOVELTY & RESEARCH CLAIMS
================================================================================

NOVEL CONTRIBUTIONS:
====================

1. HYBRID CNN-GNN ARCHITECTURE
   "We propose MSUA-Net, a novel hybrid architecture combining convolutional
   neural networks with graph neural networks for precipitation bias 
   correction. The GNN component captures spatial relationships by treating
   each grid point as a node in a graph connected to its neighbors."

2. FIRST GNN FOR INDIAN MONSOON
   "To our knowledge, this is the first application of Graph Neural Networks
   for monsoon precipitation bias correction over the Indian domain."

3. COMPREHENSIVE ATTENTION INTEGRATION
   "Our architecture integrates four types of attention mechanisms:
   Squeeze-Excitation for channel attention, CBAM for spatial attention,
   Attention Gates for skip connections, and Self-Attention for global
   context."

4. MULTI-SCALE METEOROLOGICAL FEATURES
   "The multi-scale feature extractor with 3×3, 5×5, 7×7, and 9×9 kernels
   is specifically designed to capture weather patterns at scales from
   local convective cells (~10km) to mesoscale systems (~100km)."

5. UNCERTAINTY QUANTIFICATION
   "The model provides uncertainty estimates through heteroscedastic
   regression, enabling confidence intervals for operational forecasting."
